# 上班鼓励器 · 桌面挂件

一个无边框桌面小挂件：按实际工作区间累计时长与工资，配合环形进度、工位动画、收入粒子和今日时间轴。

## 下载

Windows 免安装版有两种获取方式：

- 直接下载仓库内文件：[`dist/上班鼓励器.exe`](dist/上班鼓励器.exe)
- 或前往 **Releases** 页面下载附件 `WorkEncourager.exe`

下载后双击运行即可。需要 Windows 10/11，并已安装 WebView2 运行时（Windows 10/11 通常自带）。

SHA-256：`E3D5B68FC03EAB6F1F351671ACCF5B8129C8142457ED7D5BD5C878BD11C85F50`

## 技术方案

- **界面与动画**：HTML + CSS + 原生 JS + SVG，保留浏览器版的全部视觉细节
- **桌面外壳**：Python + pywebview，提供无边框、置顶、原生拖动、最小化、关闭和窗口位置记忆
- **本地数据**：配置文件保存在 `%APPDATA%\WorkEncourager\`
  - `config.json`：正常/加班时薪、默认计薪类型、全天加班星期、计薪时间段与工作区间
  - `settings.json`：窗口位置、置顶状态

## 运行

**最省事的方式：直接双击 `dist\上班鼓励器.exe`，无需安装 Python。**

从源码运行则要求 Windows 10/11（已安装 WebView2 运行时），Python 3.9+。

```powershell
python -m pip install -r requirements.txt
python main.py
```

也可以双击 `start.bat` 启动（无控制台窗口）。

## 桌面操作

- **拖动**：按住顶部标题区域拖动；鼠标移出窗口范围也不会中断
- **置顶**：右上角图钉按钮
- **最小化 / 关闭**：右上角窗口按钮
- **配置**：底部折叠面板，保存后写入本地 JSON 文件，重启后保留

## 时间滚轮选择

点击任意时间字段会打开小时/分钟滚轮选择器：

- **鼠标滚轮一格 = 一个选项**，不会因为一次滚轮事件跳过多项
- **触控板**按累计像素阈值换算步数，默认需要累计约 36px 才移动一项
- 快速连续滚动 5 格最多移动 5 项，滚动目标逐格累加
- 停止滚动后自动吸附并高亮当前项，字段值与高亮项一致
- 到达顶部/底部默认停止，可配置为循环
- 支持鼠标点击选项、键盘 ↑↓ 选择、触控拖动

### 可配置参数

默认参数定义在 `index.html` 的 `TIME_WHEEL_CONFIG` 中，也可以在控制台运行时修改：

```js
window.TimeWheelPicker.configure({
  wheelStep: 1,            // 一格滚轮移动几个选项
  animationMs: 160,        // 吸附动画时长
  debounceMs: 45,          // 停止滚动后多久执行最终吸附
  mouseNotchPx: 100,       // 鼠标滚轮的像素判定基准
  touchpadThresholdPx: 36, // 触控板累计多少像素移动一项
  keyboardStep: 1,         // 键盘上下键移动几个选项
  loop: false,             // 到达边界是否循环
  snap: true               // 是否启用平滑吸附
});

window.TimeWheelPicker.getConfig();
```

`snap: false` 时仍会按最近可用选项定位，但取消平滑吸附动画，确保选中值与高亮项始终一致。

## 计薪规则与优先级

累计时长只统计今日工作区间与当前时刻的重叠秒数，休息时间不计薪。

每条工时片段按以下优先级判定计薪类型：

1. **全天加班星期**：当天属于配置的星期，全部按加班时薪计算，忽略时间段规则和默认类型
2. **计薪时间段**：命中的时间段按对应类型计算
3. **默认计薪**：以上都未命中时使用

如果工时跨越多个计薪时间段，会自动拆分并分别乘以对应的正常/加班时薪，最后求和。

进度 = 累计工作秒数 ÷ 今日工作区间总秒数。

## 配置说明

- **正常时薪 / 加班时薪**：两个独立字段，没有固定比例
- **默认计薪**：正常时薪或加班时薪
- **全天加班**：周一至周日可任意多选；默认选中周六、周日；可增加、取消、修改
- **计薪时间段**：可添加任意多段，每段设置开始、结束和计薪类型；时间段之间不可重叠
- **工作区间**：仅这些时间段内的工时会计入累计与工资

主界面右侧的计薪状态会直接显示今天实际采用的计薪方式，例如：

- `周六全天加班 · ¥41.00/时`：当天命中了“全天加班星期”
- `正常计薪 · ¥28.00/时`：按时间段规则或默认类型得到正常时薪
- `正常/加班混合`：当天工时拆分后同时包含正常与加班

如果当前星期被勾选为“全天加班”，当天所有工时都会按加班时薪计算，时间段规则当天不生效。要按时间段规则计算，请在配置中取消勾选该星期并保存。鼠标悬停在计薪状态上可查看正常/加班时长明细。

## 计薪示例

正常时薪 100 元、加班时薪 200 元，默认计薪为正常，工作区间 09:00–18:00，并配置 12:00–13:00 为加班时薪：

- 周三 14:00：累计 5 小时，其中 4 小时正常、1 小时加班 → **¥600.00**
- 周六 14:00（默认周六全天加班）：5 小时全部按加班 → **¥1000.00**

旧版单时薪配置会自动迁移：原时薪同时作为正常时薪和加班时薪，原有金额不变。
